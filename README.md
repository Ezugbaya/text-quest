## Описание проекта

Игрок оказывается на космическом корабле после аварии и должен принимать решения, влияющие на дальнейшее развитие сюжета.

Проект реализован в рамках модуля 3 JavaRush University.

## Используемые технологии

- Java 11
- Servlet API 4.0
- JSP + JSTL
- Maven
- Tomcat 7
- JUnit 5
- Mockito
- Log4j2

## Архитектура проекта

Проект построен по упрощенной MVC архитектуре:

- Model — модели данных
- View — JSP страницы
- Controller — сервлеты

## Возможности проекта

- Ветвящийся сюжет
- Несколько концовок
- Хранение состояния игры через Session
- Статистика игрока
- Перезапуск игры
- Логирование действий пользователя
- Unit тесты
